# Proyecto: Landing page de HackUni 2027

Sitio informativo de una sola página para un hackatón universitario ficticio.
Lee `brief.md` para el contenido y los requisitos.

## Stack
- HTML5 semántico, CSS y JavaScript vanilla. Sin frameworks, sin build, sin npm.
- Archivos: `index.html`, `styles.css`, `script.js`. Imágenes en `assets/`.
- Debe abrirse con doble clic en `index.html` (sin servidor).

## Convenciones
- Todo el texto visible en español de México.
- Mobile-first; probar a 375 px, 768 px y 1280 px.
- Colores y tipografías como variables CSS en `:root`.
- Accesibilidad: `alt` en imágenes, `label` en cada campo, contraste AA, navegación con teclado.
- Comentarios en el código breves y en español.

## Forma de trabajar
- Antes de cambios grandes, presenta un plan corto y espera aprobación.
- Al terminar cada cambio, resume en 3 viñetas qué archivos tocaste y por qué.
- No instales dependencias ni agregues librerías externas sin preguntar.
- Nunca pongas contraseñas, tokens ni datos personales reales en el código.
